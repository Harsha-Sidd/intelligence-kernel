# Intelligence Kernel

An experimental intelligence system built from scratch, exploring rule-based processing, persistent memory, and future learning algorithms.

## Current Features

- Command-based interaction
- Rule-based command processing
- Persistent local memory stored as JSON
- Input validation and error handling
- Automated tests using Python's unittest framework

## Requirements

- Python 3.10 or newer

The current implementation uses Python's standard library and does not require external packages.

## Run

From the project directory:

```bash
python main.py
